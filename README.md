## ✨ Project Overview

**Cinematic Bloom Design** is a high-end creative studio website that redefines the digital experience for luxury brands. Inspired by cutting-edge design studios and premium technology experiences, this portfolio website combines **cinematic aesthetics, experimental interactions, and sophisticated editorial design** to create an unforgettable first impression.

This isn't just another portfolio—it's a **showcase of design excellence**, crafted for creative professionals, agencies, and brands who demand premium visual experiences.

### 🎯 Core Vision

Create a website that feels like:
- ✅ A luxury creative agency landing page
- ✅ An experimental tech product showcase
- ✅ A high-end editorial campaign
- ✅ A premium motion design portfolio

- Large oversized headline: **"DESIGN, REIMAGINED."**

### 3️⃣ **Editorial Statement**
- Large typography-focused section
- Headline: **"IDEAS THAT GROW BEYOND THE EXPECTED."**

- Full-width dark botanical/futuristic visuals

## 🎬 Animation Strategy

### Animation Principles
- **Expensive Feel:** 300–800ms transitions (never flashy)
- **Cinematic Quality:** Smooth easing functions
- **Scroll-Triggered:** Fade-ins, text reveals, parallax
- **Hover Interactions:** Smooth micro-animations
- **Image Movements:** Slow zoom, parallax effects
- **Text Animations:** Letter spacing, fade-in, upward drift

### Key Animation Features
✅ Smooth page scrolling  
✅ Scroll-triggered fade-ins  
✅ Text reveal animations  
✅ Image parallax effects  
✅ Slow image zoom on hover  
✅ Button hover transitions  
✅ Section transition effects  
✅ Subtle background movement

## 🚀 Getting Started

### Prerequisites
- **Node.js** 18+ (recommended: [nvm](https://github.com/nvm-sh/nvm))
- **npm** or **yarn**

### Installation

```bash
# Clone the repository
git clone https://github.com/Muhammad-Ahmad-CO/cinematic-bloom-design.git
cd cinematic-bloom-design

# Install dependencies
npm install

# Start development server
npm run dev

# Open http://localhost:5173 in your browser
```

### Available Scripts

```bash
# Development server with hot reload
npm run dev

# Build for production
npm run build

# Build for development mode
npm run build:dev

# Preview production build
npm run preview

# Lint code with ESLint
npm run lint

# Format code with Prettier
npm run format
```
