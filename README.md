# Lumina Studio

Create a premium, highly polished, cinematic website inspired by the website shown on the laptop in the reference video.

IMPORTANT:
Recreate the visual design language, layout structure, animations, spacing, typography hierarchy, dark aesthetic, and overall premium feel as closely as possible, while using original branding, original copy, and original assets. Do not simply copy any copyrighted logos, text, images, or proprietary assets.

Overall Design

Build a modern full-screen landing page with a luxurious, experimental, technology-meets-nature aesthetic.

The website should feel:

Premium

Minimal

Cinematic

Futuristic

Editorial

High-end

Immersive

Professional

Use a predominantly black / near-black background with deep forest green accents and subtle warm highlights.

Color palette:

Background: #050706 / near-black

Secondary background: #0A100D

Deep green: #10251A

Accent green: #6FAF70

Soft white: #F2F2ED

Muted text: #9A9F99

Very subtle warm orange/gold accent where appropriate

Header

Create a minimal fixed navigation bar.

Left:

Small elegant brand logo/wordmark

Center/right navigation:

Work

About

Process

Contact

Right side:

Small rounded CTA button such as "Start a Project"

Header should remain subtle and almost disappear into the dark background.

Use thin typography, generous spacing and smooth hover animations.

Hero Section

Create a full-screen hero section.

Use a large cinematic background visual showing an abstract combination of:

Dark natural textures

Green botanical elements

Organic shapes

Subtle futuristic lighting

Very dark environment

Add a large oversized headline in uppercase:

"DESIGN, REIMAGINED."

The typography should be extremely large, clean and editorial.

Add a short supporting paragraph underneath.

Add a small rounded button:
"EXPLORE"

Include subtle animated movement in the background.

The hero should immediately feel like a premium creative studio / futuristic product website.

Section 2 — Large Editorial Statement

Create a large typography-focused section.

Headline:

"IDEAS THAT GROW BEYOND THE EXPECTED."

Use oversized typography with some words highlighted in muted green.

Keep a lot of negative space.

As the user scrolls, animate the text smoothly using:

Fade-in

Slight upward movement

Letter spacing transitions

Section 3 — Full Width Visual

Create a large immersive image/video section.

Use a dark botanical / futuristic visual.

The image should occupy almost the entire viewport width.

Overlay a small label in the corner.

Add subtle parallax movement while scrolling.

The visual should feel like a luxury editorial campaign rather than a normal website image.

Section 4 — Services / Features

Create a minimal grid of 4–6 items.

Example:

01 — Creative Direction
02 — Digital Experiences
03 — Brand Systems
04 — Motion Design
05 — Interactive Development
06 — Visual Strategy

Each item should have:

Large number

Large title

Short description

Thin divider line

On hover:

Title slightly moves

Green accent appears

Background subtly changes

Smooth 300–500ms transition

Section 5 — Experimental Visual Section

Create a dramatic dark section featuring a large abstract visual.

Use an organic glowing shape / futuristic object in the center.

The object should slowly animate or rotate.

Add minimal typography around it.

The overall effect should resemble an expensive technology advertisement.

Section 6 — Large Statement

Create another oversized editorial statement:

"BUILT TO MAKE PEOPLE LOOK TWICE."

Use very large typography.

Animate each line as it enters the viewport.

Keep the section visually minimal.

Section 7 — Work / Projects

Create a portfolio section containing large horizontal project cards.

Each project should have:

Large image

Project title

Category

Year

Cards should have subtle rounded corners.

On hover:

Image slowly zooms

Overlay becomes slightly darker

Project title moves upward

Cursor interaction feels smooth

Use dark green / black visual assets.

Section 8 — Final CTA

Create a dramatic full-screen final section.

Large headline:

"LET'S CREATE SOMETHING UNEXPECTED."

Below it:
"Start a conversation →"

Use a dark green-black background with a subtle animated organic texture.

Make this section visually powerful but minimal.

Footer

Create a clean dark footer.

Include:

Logo

Navigation

Social links

Email

Copyright

Small location text

Use thin borders and muted typography.

Typography

Use a premium modern sans-serif font.

Recommended:

Inter

Helvetica Neue

Neue Montreal

Manrope

Headings:

Very large

Tight letter spacing

Uppercase where appropriate

Font weight 500–700

Body:

Small

Clean

High readability

Muted gray

Animations

Animations are extremely important.

Implement:

Smooth page scrolling

Scroll-triggered fade-ins

Text reveal animations

Image parallax

Slow image zoom

Hover transitions

Button hover animations

Smooth section transitions

Subtle background movement

Animations must feel expensive and cinematic, NOT flashy.

Use approximately 300–800ms transitions depending on the interaction.

Responsive Design

The website must work perfectly on:

Desktop

Laptop

Tablet

Mobile

Desktop should preserve the cinematic spacious layout.

On mobile:

Stack content vertically

Reduce heading sizes intelligently

Maintain generous spacing

Keep animations smooth

Make navigation mobile-friendly

Technical Requirements

Build this as a production-quality responsive website.

Use:

React

Tailwind CSS

Modern component architecture

Clean reusable components

CSS variables for the design system

Optimized images

Lazy loading

Semantic HTML

Accessible buttons and navigation

Proper keyboard navigation

Avoid unnecessary UI elements.

The final result should NOT look like a generic SaaS template.

It should feel like a high-end creative agency / experimental digital studio website shown through a premium laptop screen.

Most important priorities:

Visual quality

Dark cinematic aesthetic

Typography

Large editorial layouts

Premium animations

Strong imagery

Generous whitespace

Smooth scrolling

Responsive behavior

Overall resemblance to the visual atmosphere of the reference video

Make the first viewport extremely impressive because this is the most important part of the website.
